
# NoteToGo

**Forge your musical instincts.**

NoteToGo is a gamified music ear-training web application built with Python and NiceGUI.

## Project Goal

Help musicians improve their ability to recognize musical notes by ear through interactive exercises.

## MVP Features (Planned)

- Piano and guitar note recognition
- Seven natural notes: C, D, E, F, G, A, B
- Five difficulty levels
- XP and streak rewards
- Persistent player progression
- Session statistics and performance tracking
- Responsive web interface

## Technology Stack

- Python 3.12+
- NiceGUI
- SQLite
- pytest
- Git

## Development Setup

The following commands assume Ubuntu or WSL 2.

### Create a virtual environment

```bash
python3 -m venv venv
source venv/bin/activate
```

### Install dependencies

```bash
python -m pip install -r requirements.txt
```
